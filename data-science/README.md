# Vitara Data Science

Data Science repository for the Vitara project, containing data collection, preprocessing pipelines, exploratory analysis, feature engineering, and technical documentation.

## Overview

This repository serves as the central workspace for preparing datasets used in the Vitara project. The notebooks focus on transforming raw data into analysis-ready datasets through cleaning, preprocessing, balancing, feature extraction, and validation processes.

## Scope

This repository focuses on:

* Data Gathering
* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Dataset Balancing
* Data Validation
* A/B Testing Preparation
* Technical Documentation

No model training or deployment workflows are included in this repository.

## Dataset Domains

### NLP Emotion Dataset

Preprocessing pipeline for emotion and stress analysis:

* Text cleaning
* Case normalization
* Label standardization
* Class balancing
* Dataset preparation

### Keystroke Dynamics Dataset

Behavioral dataset preparation including:

* Feature extraction
* Inter-key timing generation
* Typing speed metrics
* Session-level aggregation
* Synthetic data preparation

### Sleep Scoring Dataset

Health-related dataset preprocessing including:

* Missing value handling
* Feature normalization
* Sleep metric preparation
* Data quality validation

### Food Vision Dataset

Computer vision dataset preparation including:

* Image organization
* Class mapping
* Label validation
* Nutrition category integration
* Dataset standardization
